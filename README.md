# Nostra - E-commerce Website

A beginner-friendly responsive fashion e-commerce website created with HTML, CSS and JavaScript.

## Pages
- index.html - Home page
- collections.html - Collections page
- contact.html - Contact Us page

## Features
- Responsive navigation with mobile menu
- Hero section with 3 rotating images
- Large previous/next arrow buttons in the hero
- Brands section
- Customer experience section
- New Arrivals and Most Wanted sections
- Limited Offer section
- Newsletter form
- Collections search using JavaScript
- Collections filter using JavaScript
- Contact form validation/submit message
- Responsive design for desktop, tablet and mobile

## Purpose
This project was created as a practice project to improve my skills in HTML, CSS, JavaScript, responsive design, and website layout development.
